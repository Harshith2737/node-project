# Telangana Heritage — College Project MVP

A full-stack-ready prototype for Sustainable Tourism and Cultural Heritage Preservation in Telangana.

## Included
- Responsive tourism UI
- Heritage destination explorer with search/filter
- Interactive map-style prototype
- Trip planner
- AI guide demo
- Culture archive contribution flow
- Sustainability score
- Carbon calculator
- Heritage issue reporting workflow
- Express REST API starter

## Run the frontend
Open `frontend/index.html` in a browser.

## Run the backend
1. Install Node.js.
2. Open terminal in `backend`.
3. Run:
   npm init -y
   npm install express cors
   node server.js
4. API: http://localhost:5000/api/health
